# Unified Modeling Language - Basics

*Sep-2024*

Tags: Modeling, Requirements Engineering, Use Case Diagrams, Activity Diagrams, Domain Modeling, Component Diagrams, Sequence Diagrams, State Diagrams

Notes from a UML basics course, covering how UML is used to model software across requirements, architecture and detailed design. On the requirements side: use case diagrams, activity diagrams for each scenario of a use case (positive, negative, error), and a domain model built with class diagrams in the customer's own vocabulary. On the architecture side: component diagrams (ports, interfaces, composites) for the static view, sequence diagrams for runtime behaviour, and state diagrams for states and their transitions.
