# Software Architecture - Basics-B (foundation for CPSA-F certification)

*May-2025*

Tags: Architecture Design, Impact Factor Analysis, SOLID Principles, Architecture Views, Architectural Patterns, Hexagonal Architecture, Design Principles, Design Patterns

Notes from a software architecture foundation course preparing for the iSAQB CPSA-F certification. Topics: what architecture is, its building blocks and goals, and why it is shaped more by quality requirements than by functional ones; analysis with use cases and domain models; identifying and analysing the factors that most affect architectural decisions; design approaches (top-down, bottom-up, upfront, emergent, iterative); design principles (loose coupling, strong cohesion, open-closed, information hiding); architecture views (context, building block, runtime, deployment); and architectural patterns (layers, ports and adapters, pipes and filters, microservices, blackboard).
