# Cybersecurity Best Practices

*Feb-2026*

Tags: Cybersecurity, Security Frameworks, Defense in Depth, Network Security, Case Study

Notes from Coursera's *Cybersecurity Best Practices*: a recap of the CIA triad; a Maersk case study showing a security programme run as risk assessment → framework selection → gap assessment → roadmap; an overview of the main security frameworks and standards (NIST CSF, CIS Controls, ISO/IEC 27001, PCI DSS, HIPAA Security Rule, OWASP Top Ten, SANS); and the basics of securing a network through segmentation, VLANs, subnets and access control rules.
